TANK DESIGNER · HOI4 1.19.2

Build the tank for the division you actually want to field

The Tank Designer combines the planner's certified 1.19.2 chassis and module data with division-level analysis, so a tank variant can be judged by what it does to the whole template rather than by isolated armor or attack numbers.

Compare module tradeoffs directly

Choose the chassis, role and compatible modules, then inspect the resulting attack profile, armor, piercing, breakthrough, reliability, speed and production cost. Source-backed compatibility and module-slot rules are enforced so the comparison stays within the retained vanilla 1.19.2 design space.

Feed the result into Division Lab

A tank variant matters because it changes the battalion using it. Send the design into the division workflow and compare how the finished template performs against a specific opponent. This makes it easier to see when extra armor crosses a threshold, when more soft or hard attack matters, or when an expensive module barely changes the actual matchup.

Use cost as part of the design question

Higher combat stats can come with higher IC and strategic-resource pressure. The planner keeps those production considerations visible so a design can be evaluated as part of an army you need to manufacture, not as a stat card with unlimited factories.

Best way to experiment

Start with a baseline design, duplicate the scenario, and change one major module or upgrade at a time. Then compare both the tank card and the resulting division performance. That isolates the cause of the improvement and makes expensive changes easier to justify or reject.

Accuracy boundary

Tank chassis, module and compatibility data are retained from the supplied 1.19.2 source corpus where certified. Runtime combat interpretation remains separated by evidence class. See the methodology page for the current certification boundary.
