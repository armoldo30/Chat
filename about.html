ABOUT THE PROJECT

HOI4 War Planner

HOI4 War Planner is an independent, fan-made theorycrafting tool for Hearts of Iron IV. The current public release is 0.17.17 and uses a bundled vanilla 1.19.3 data baseline.

Why I built it

HOI4 gives you a lot of knobs to turn, but it is not always obvious which one actually changed a fight. This site puts division design, equipment, doctrine, terrain and the opposing template in one place so you can recreate a matchup and test it instead of guessing.

It is not meant to replace the game or claim access to hidden engine behavior. Where executable behavior has been validated, the site states the controlled boundary; unresolved behavior stays labeled rather than being presented as exact.

What is in the planner

The main tools are Division Lab, Counter Analysis, Tank Designer, Air Lab and Division Gauntlet. The planner also carries technology, doctrine, MIO and terrain assumptions into the parts of the model where they are supported.

Full Gauntlet uses 10,000 deterministic opponents across eight terrain types while attacking and defending, for 160,000 matchup checks.

How accuracy is handled

The project separates values read from the retained game files from behavior inferred from the executable and from analysis created by the planner itself. Those evidence classes are kept visible instead of being blended into one “exact” claim.

The methodology page has the details.

Privacy and independence

No account is required. Planner state is stored locally in the browser. The site is not affiliated with or endorsed by Paradox Interactive.

Advertising is not currently enabled.

Found something wrong?

Please report bad data, broken behavior, strange Counter recommendations or UI problems through the GitHub issue tracker linked in the site footer. Real examples are much more useful than vague “this seems off” reports.
