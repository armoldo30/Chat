ABOUT THE PROJECT

HOI4 War Planner

A free, fan-made theorycrafting tool for Hearts of Iron IV. The current public release is 0.17.16 and uses a vanilla HOI4 1.19.3 data baseline.

Why I built it

HOI4 makes it easy to look at two divisions and know that one worked better. It is much harder to tell why. Armor and piercing, hardness, attack type, organization, width, terrain, doctrine, equipment and cost can all move the answer at the same time.

The planner puts those pieces in one place. You can rebuild a matchup from a game, try a counter, compare a tank or aircraft change, and see whether the result actually moves.

What is in it

Division Lab handles direct matchups. Counter Analysis tests bounded changes against the enemy you built. Tank Designer and Air Lab let you compare equipment variants. Division Gauntlet takes a division out of that single matchup and stress-tests it against a much wider opponent set.

Full Gauntlet uses 10,000 deterministic opponents across eight terrain types while attacking and defending, for 160,000 matchup checks.

Accuracy matters

This is still a model of HOI4, not HOI4 itself. Values taken directly from the supplied game files are kept separate from executable-inferred behavior and from analysis created by the planner. Oracle testing is used when a mechanic needs controlled evidence from the real executable.

If something is not known well enough, the goal is to say so rather than quietly turn an approximation into a fact. The methodology page explains the labels and current boundary.

Privacy and independence

You do not need an account to use the planner. Planner state is stored locally in your browser. HOI4 War Planner is an unofficial fan project and is not affiliated with or endorsed by Paradox Interactive.

Found something wrong?

Please report it. Bad data, strange Counter recommendations, broken mobile layouts and edge cases are all useful feedback. The public GitHub issue tracker is linked in the site footer.
